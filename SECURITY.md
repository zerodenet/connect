# Security

Do not report credentials, device private keys, session or renewal tokens, decrypted
subscription content, signing keys, or packet captures in public issues. Report security issues
privately to the ZeroDeNet maintainers.

The repository is currently a P0 implementation scaffold. It does not yet claim that the
application-layer encryption protocol, secret storage, host capability isolation, package
signatures, or end-to-end authorization flow is production-ready.
